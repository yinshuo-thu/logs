你是模型机上的研究工程师。请直接检查当前项目、实现数据与训练入口、启动并监控训练，在启动后 36 小时内交付首轮结果；未达标时进入第 6 节的 Goal 模式迭代。用台湾约一年、香港约半年的全部可用股票 snapshot，先做双市场联合预训练，再分别针对台湾、香港微调。关心的问题是：相同的原始盘口输入下，多头预训练能否提高单市场未来 60 秒收益 IC？0.30 是期望值，实际结果按 TW/HK × validation/test 四格分别报告。沿用已有数据读取、交易日历、评估和 checkpoint 代码。数据、预测和权重留在模型机。

## 0 · 启动与阶段性资源检查

将本文全文复制到模型机的 Goal 模式，直接复用或补齐当前项目的数据读取、训练和评估入口。初始随机种子取 20261121。36h 是首轮汇报节点。每个 epoch 结束、每个较大的数据分片或 checkpoint 写完，由 agent 用模型机已有监控查看主机 RAM 和 EXPORT 所在文件系统的使用率。Linux 上 RAM 按 `100 × (1 − MemAvailable / MemTotal)` 从 `/proc/meminfo` 读取，磁盘用 `df -P /实际路径/EXPORT` 查看并记录 Use%；容器有内存配额时另看作业面板的配额使用率。达到 88% 时，先释放已用完的缓存、缩小后续数据块或暂停可选导出，目标保持在 90% 以下。采用普通分片写入，各市场各写自己的目录。阶段检查不能测出两个检查点之间的瞬时峰值。

每个 rank 初始设 1 个 DataLoader worker、prefetch_factor=1，关闭 pin_memory 和 persistent_workers。数据按日流式读取，逐轮保留 checkpoint，best 仅引用已有文件。L4 每卡通过一次真实训练步试 4/8/16 个片段，用吞吐最高且整卡显存峰值 <80% 的档；每个进程在建模前绑定自己的 local_rank，并将 PyTorch 显存分配器上限设为单卡容量的 82%。

## 1 · 冻结数据与评估口径（0–3h）

- 自动定位两市场分日 snapshot、证券映射和已有实验。记录真实字段、日期范围、采样间隔、时钟和既有 1min IC 定义。若有历史成绩，带上代码版本、日期和口径；此前讲义给出的是待检验假设。开跑前固定主 IC。若项目有明确的既有主 IC，沿用并同时报告下述可比较口径；否则下述 Pearson 截面 IC 为主。
- 决策点默认同一市场同步的 5 秒网格。每个时点只取当时已收到的最后有效报价；没有接收时钟时用数据源时间并写明。m=(bid1+ask1)/2，r_h=10,000×ln[m(t+h)/m(t)]，单位 bp。两端用向后 as-of，处于同一连续交易段；陈旧上限按市场预先固定（默认 max(5s, 3×训练期典型推送间隔)）。停牌、交叉盘、越午休/收盘或缺端点屏蔽。保留有效的零收益。
- 各市场同一时刻对可用股票计算 Pearson(pred, r60)，至少 20 只且两边方差非零。先按时点平均为日 IC，再等权平均交易日；同步报有效日、时点、股票数及覆盖率。辅报截面 RankIC 与按股日计算的时序 Pearson IC。评估始终比较同一组有效锚点，不用全市场所有样本混成一个相关系数。
- 在共同覆盖期按两个市场共同交易日期确定边界：最后约 15 个共同交易日留作 test，紧前约 15 个留作 validation。按两个边界日期给各市场所有交易日分 train/val/test，并以共同覆盖期末为本轮评估截止；台湾更早历史全部纳入 train。覆盖不足则在开跑前按共同日期 70/15/15 切。将实际边界写入配置。切分处删除最远监督端点跨界的训练锚点，所有预训练头也服从切分。测试标签只在各市场方案锁定后统一评一次。
- 一次冒烟即可：抽台港各一日查字段与收益单位、确认截断 t 后输入不会改变 t 的预测、跑通一次前反向和 IC。CPU 并行训练一个便宜基线：当前 snapshot 的相同归一化字段 → Ridge → r60。

## 2 · 输入与主干

- 输入只用 snapshot 本身约 20–30 个可见数值字段（以真实 schema 为准）、字段存在性、推送时间差和市场标记。价格字段统一用当日该证券的开盘价归一化，计算 10,000 × ln(档位价格 / 开盘价)。使用截至该帧已发布的开盘成交价，未到达前将开盘坐标标为缺失；若数据源不提供开盘价，以当日首笔可见成交价作代理并记录来源和覆盖率。开盘参考按证券、当地交易日重置，午休后继续使用早盘开盘价。另保留 `10,000 × ln(本帧中价 / 前帧中价)`，两帧须同证券、同连续交易段且价格有限并为正；断流后重置前值。该变化用于区分快速跳价与缓慢漂移。屏蔽日内二次中心化，给开盘坐标保留连续线性旁路，避免 PLE 两端截断把大幅上涨或下跌压成同一个值。收益标签仍以决策时刻中价为起点。
- 数量按市场、证券、字段（含买卖侧、档位）使用前 5 个本市场交易日的历史参考。每个完整交易日先算有效观察的日内中位数，再取前五个日中位数的中位数 R，编码为 `log1p(q/R)`。在日初冻结参考、日终才更新历史。停牌或字段缺失的交易日占一个日历位置，留空；不足五日用已有记录并传有效天数，空历史或 R≤0 时屏蔽该字段。只取有限且非负的量；当日真实零量在参考有效时编码为 0。缺失项填 0 并单列有效位。成交累计量先按字段定义还原为增量，识别计数器重置，再用同口径的历史增量做参考。验证和测试同样逐日向前滚动，只使用此前已结束日期的可观测行情。禁止额外构造 OFI、技术因子或加入逐笔数据。每次推送产生一个 token，按连续交易段打包；同一时点有多个 5 秒锚点复用最近隐状态及其年龄，避免为每个锚点重复读取整窗。无历史或过旧则跳过。按交易时段重置状态。
- PLE 对每个数值字段按训练折分位数取 16 段，去重重合结点；每段编码该区间已填比例，端外截断并保留越界位，常数字段单独处理。两市同语义字段共享投影，量纲差异用各市场训练统计校准。PLE、缺失位、时间编码拼接后投影到 d=128。主干用因果 Mamba，4 层，d_state=16，expand=2。训练片段 256 个 snapshot，前 32 个作 warm-up，其余有效位置可共享前向；验证与测试按时间顺序回放并一致处理状态。
- 用 PyTorch、已兼容的 mamba-ssm、BF16（不支持时用带 scaler 的 FP16）、AdamW、梯度裁剪 1.0。预训练 lr=3e-4、wd=0.01、5% warm-up 后余弦衰减。每卡批量沿用第 0 节的实测值，以梯度累积保持同一候选有效批量。两卡共享相同字段表。若 fused kernel 在 30 分钟内仍无法打通，使用环境已有的可用 Mamba 实现；若只能以 GRU 保底，明确标注主干替代。

## 3 · 双市场多头预训练（3–22h）

| 头 | 标签与损失 | 权重 |
|---|---|---:|
| 60s 收益（主头） | r60 / s60，Huber(δ=1)；s60 为对应市场训练折收益的稳健尺度，尺度退化用训练标准差并设正下限 | 1.00 |
| 多周期收益 | r10、r120、r300，各用本市场、本周期训练尺度，三个 Huber 取均值 | 0.25 |
| 下一帧盘口 | 预测下一条真实推送的中价变化(bp)、价差变化(bp)、可用前 3 档双侧 log 深度变化；按字段训练尺度标准化，Huber 均值 | 0.25 |
| 未来波动 | 在有效 5 秒中价网格算未来 60s 和 300s 的 RV=Σr5²（bp²），回归标准化 log(1+RV)，Huber | 0.15 |
| 市场方向 | 从当期可见且两端有效的股票构造同市场 60s 等权平均收益，按训练期固定阈值分上/平/下，交叉熵；同一市场时点等权 | 0.10 |
| 掩码重建 | 约 1/4 训练片段只做重建：随机遮约 15% 有效字段，交替用同侧同档价量组或连续 4 帧的字段块；掩码在 PLE 前施加，同步屏蔽能还原目标的中价变化及下一帧差分旁路；采用预测时已知的开盘参考，同时遮住对应的连续旁路及同义字段。因果状态恢复原始归一化目标，只在被遮处算 Huber | 0.15 |

干净片段训练前五头，出分始终用干净输入。每头先对有效标签取平均，再加权；无有效目标则跳过。下一帧须在同一时段且间隔≤300s，长时间无快照不硬填。市场方向仅作未来标签；其训练阈值按唯一市场时点拟合，缺少有效横截面时跳过。训练尺度取训练折 MAD×1.4826，若为零用训练标准差，下限 1e-3 bp；评估用原始 bp 标签，主收益头输出换回 bp 评 IC。把这组实验标作含收益监督的联合预训练。

启动一个双卡 DDP 作业。每个全局优化步包含 TW 和 HK 的训练片段，共享一套 PLE 投影、Mamba 主干及预测头；两个 rank 同步梯度并更新同一组权重。每个片段只含一个市场、一只证券的连续交易时段。按日期、证券分片连续读取，DDP 各 rank 读取互斥分片；每个 epoch 轮过全部可用训练分片，每个市场每个任务按跨 rank 的有效数归一，然后按两市场等权。DDP 默认平均各 rank 梯度时，本地可微分 loss sum 乘 world_size / 全局有效数，只 all-reduce 分母；全局无标签时该头图连通、梯度为零。首 200 个稳定 step 测端到端吞吐，估算含验证的 epoch 时长。目标 3–5 个 epoch，第 22 小时留出微调。若预计不足 3 轮，先改成每 10s/20s 一个训练监督锚点；若主耗时在扫描 token，再降到 d=96、3 层，并对每个证券日按固定步长轮换抽连续片段，保留全市场、全训练日期覆盖。记录每轮实际读取的原始帧数、覆盖率与抽样步长；抽样轮和全量遍历分别注明。评估网格固定 5s。每轮保存可恢复 checkpoint（权重、优化器、scheduler、随机状态、步数、字段/PLE 配置），输出 TW/HK val IC 与各头有效数和 loss。取两市 val 主 IC 等权均值最高的一轮为共享起点；同分选更早轮。将该轮登记为 joint/best 并记录文件哈希。

## 4 · 单市场微调与对照（22–33h）

退出 DDP，启动两个独立的单卡作业：GPU 0 只读 TW 训练集，GPU 1 只读 HK 训练集。两者各自加载 joint/best 的副本、重置优化器，分别写入 finetune/TW 和 finetune/HK；每种微调方案都从该市场的同一初始副本重新开始。每市场从同一个最佳联合 checkpoint 出发，保留 60s 头，只用该市场的 60s 收益监督微调。每轮按本市场 val 主 IC 选优，最多 3 轮，连续两轮不改善即停。每个市场只在本市场 validation 上选方案：

1. 先评联合头和冻结主干的线性探针（lr=1e-3），并留出时间跑同主干单市场从零训练 r60 对照（lr=3e-4、相同下游更新步数）。它们分别衡量直接迁移、状态可读性和完整预训练流程增益。
2. 全量微调的头 lr=3e-4。主干 lr 候选为 1e-5、3e-5。若主指标是截面 Pearson，使用 `L = mean_valid[Huber(pred, r60/s60; δ=1)] + λ × mean_group[1 − Pearson(pred, r60)]`，比较 λ=0 和 0.15。pred 与收益目标使用相同训练尺度。第一项只在有效个股上平均，第二项对同市场、同一 5s 时点的有效截面等权平均；任一侧方差为零则跳过该截面，整批均无合格截面时只计第一项。输入形状为 [时点组, 股票]，每个有效组至少 20 只；相同股票只出现一次。随机选时点，再在组内均匀选最多 32 只同期股票。显存紧时按单个时点顺序处理、跨时点梯度累积，必要时采用 activation checkpointing；仍无法容纳 20 只时仅用 Huber，并记录原因。禁止跨市场、跨时间或在互不关联的 microbatch 上凑相关系数。若项目主 IC 是时序口径，保留 Huber 并按既有口径选 lr。若主干批量试验最多容纳 16 个片段，先验证冻结状态的线性头上完整截面相关损失，再决定是否给全量微调启用该项。
3. 两卡各自对本市场执行等预算筛选。每个合法组合从同一 joint/best 和随机种子开始，用相同顺序的训练锚点、固定验证面板，试跑最多 0.25 个训练 epoch。先实测单步耗时；所有短跑合计不超过该市场微调预算的 25%。若超时，先固定 lr=3e-5 只试损失开关，再退为单一 Huber 基线。按该市场 val 主 IC 排序，平分选 Huber；保留前两名，余时从各自 checkpoint 续跑至相同总预算（最多 3 轮），在完整验证集择优。未跑候选明确列为未测。
4. 预算仍有余量再试 LoRA（r=4、α=8、adapter lr=3e-4）并确认 adapter 有非零梯度。若希望单独归因辅助任务，再做同两市、同预算的 r60-only 联合预训练。小样本验证无法识别唯一最优值，交付时报告实测候选及相对简单基线的按日配对差异。

## 5 · 锁定结果与交付（33–36h）

先写出每市场实际 lr、IC 权重、批量、截断长度、选中轮次、验证 IC 与候选试验步数（包括资源触发的降级）。两市分别按 validation 主 IC 选好微调方案、轮次与权重，写入 selection.json。若任一市场 val IC <0.30，保留 test 封存，先报告已测两格并进入迭代；两市验证均达到门槛后，锁定并一次性对模型和预先指定的基线做独立 test。输出一张表：市场、模型、val/test 1min Pearson IC、RankIC、时序 IC、有效日及相对基线增量。对同一批预测再计算与 10–60 秒收益的 IC，判断信号是否集中于前十秒。用按日期配对的块 bootstrap 给主 IC 与增量估计区间，注明测试天数少时的不确定性。

交付可复跑命令、冻结配置/数据清单、每轮 metrics.csv 与 checkpoint、最优路径、四格结果和一段中文结论；列出实际 GPU 小时与未完成对照。如某格仍封存或缺少新留出期，明确标注待测。首轮优先交付可恢复的预训→两市微调流程与实际进度。

## 6 · Goal 模式的验收与续跑

目标为 TW/HK 各自 validation、独立 test 的主 1min IC 均 ≥0.30，以未四舍五入值判断。36h 先汇报并保存状态；未达标时主动读取已有配置、逐日 IC、基线差异、耗时及资源记录，继续有依据的实验。每轮把“观察 → 可证伪的解释 → 一项改动 → 预期改善的指标和切片 → 实际成对差异、GPU 小时及保留/回退决定”追加到实验日志。首选只改一个因素，固定其他条件和评估股票池。

**续跑约定。** 每轮结束或到达 36h 汇报点时，在模型机实验日志末尾留一条恢复记录：本轮配置与 checkpoint 路径、两市各自锁定的模型版本、四格 IC（未测填「待测」）、已使用的测试日期、下一项实验及其判断依据。恢复时先核对在跑作业，接着监控或从最近可恢复的 checkpoint 继续。已有结果足以支持下一项实验时直接执行。四格成绩须能追溯到各市场同一冻结版本的验证与独立测试；若仅缺新的未见测试日期，报告「待独立验收」和所需日期，保留预测与权重。

| 训练或验证证据 | 优先尝试的实验 |
|---|---|
| 开盘后表现不稳，大幅行情中 PLE 越界多 | 用相同锚点对照开盘参考覆盖、代理价偏差和连续旁路；检验增益能否延续到午后 |
| 量能分布随活跃度变化，低流动组历史参考常为零 | 固定五日因果窗口，对照历史中位数与均值；按有效历史天数检查改善来自尺度还是样本减少 |
| 辅助头 loss 下降、主 IC 停滞 | 同预算降低单个疑似冲突的辅助头权重，与 r60-only 联合对照比较 |
| 0–10 秒有效，10–60 秒弱 | 加入后段收益的辅助头或延长物理回看；保持最终 60 秒标签和决策延迟 |
| GPU 空闲或读取耗时占主导 | 按日预计算归一化统计、减少重复读窗；在固定样本与步数下比较 samples/s 和 IC/GPU 小时 |

改进先在训练期内的多个向前滚动切分与固定验证期复核，按交易日成对比较，记录所有尝试和失败。test 只对冻结版本揭盲。若已揭盲的 test 未达标，记录原成绩，仅用训练/验证证据解释并继续开发；下一次独立验收使用预留且从未查看的后续日期或新到数据。没有新日期时继续可证伪的开发实验，状态写为“新版本独立测试待验证”。禁止通过反转符号、删掉差股票/差日期、替换主 IC、反复查看同一测试集或只报告最好种子来达标。若连续尝试无法复现改善，保留最佳可复现版本，报告证据缺口，再用新假设或新数据推进。现在直接执行。
