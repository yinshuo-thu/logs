# 双 L4 · 36 小时台湾 / 香港 snapshot 一分钟收益实验

你是模型机上的研究工程师。请直接检查当前项目、实现数据与训练入口、启动并监控训练，在启动后 36 小时内交付结果。用台湾约一年、香港约半年的全部可用股票 snapshot，先做双市场联合预训练，再分别针对台湾、香港微调。关心的问题是：相同的原始盘口输入下，多头预训练能否提高单市场未来 60 秒收益 IC？0.30 是期望值，实际结果按 TW/HK × validation/test 四格分别报告。沿用已有数据读取、交易日历、评估和 checkpoint 代码。数据、预测和权重留在模型机。

## 0 · 模型机执行入口与资源边界

将本日期目录的 [snapshot_config.py](snapshot_config.py) 和 [export_guard.py](export_guard.py) 与本文一起取到模型机。实现或复用一个 `run_experiment.sh` 串起所有阶段，用 `snapshot_config.CFG` 作为参数源，实际选中的覆盖值写入运行配置。命令在该目录执行：

```bash
python snapshot_config.py
python export_guard.py --export /actual/path/EXPORT -- bash run_experiment.sh
```

将路径替换成模型机现有 EXPORT。第二条命令覆盖预处理、两个 DDP rank、两个微调进程、worker、评估及导出。所有子任务在该作业内启动并等待退出，36h 自启动计。守护程序使用 Linux cgroup v2、Python 3.9+ 和 systemd 用户 scope，按主机和有限父 cgroup 中更紧的剩余预算设置整个作业的 MemoryMax（启动时为既有负载留足空间，总占用目标 ≤85%），并在启动训练前读回硬上限。每次续跑沿用初次启动的绝对截止时刻，在 run_experiment.sh 中传入剩余时间。调度器环境可传 `--existing-scope` 使用已有独占作业 cgroup，需有符合预算的有限 memory.max。没有可验证上限时先建立受限作业再启动。

- **主机 RAM**：每秒观察主机与有限父组，达到 88% 终止本次作业；每分钟打印观测峰值。单次只载入一个有上界的行组或 chunk，PLE 分位数用有界流式采样拟合。DataLoader 初始每 rank 1 worker、prefetch=1、关 pin/persistent；Ridge 分块累加充分统计量。预测、指标、探针状态按日期流式计算，禁止全市场 concat 或把全部隐状态放进内存。
- **EXPORT 所在文件系统**：所有持久写入统一走 `with atomic_export(EXPORT_DIR, relative_name) as f:`，向 f 写字节或 `torch.save(state, f)`。两市共享同一根目录与文件锁。该接口在同分区写临时文件，按块检查可用空间，预计超 88% 时拒写并保留旧文件，完成后原子替换。预估每轮 checkpoint × 轮数的空间，best 用小型索引引用原 checkpoint；预测按交易日分片。若空间紧张，先省略可选的隐状态缓存，保留逐轮权重。原始行情只读。作业主动保留距 90% 的余量；同机其他用户的突发负载或独立写盘须由独占配额保障。
- **L4 显存**：每进程绑一卡，创建模型前调用 `configure_gpu(local_rank)`；PyTorch 分配器上限 82%。冒烟时用最长序列、真实任务头和优化器更新试每卡 4/8/16 段，选吞吐最高且实测整卡峰值 <80% 的档；不合格则降至 2/1 或缩小模型。NCCL/驱动另计，监控整卡而非只看 allocated。将 OOM 与资源退出记录为失败/续跑，不计作完整 epoch。

## 1 · 冻结数据与评估口径（0–3h）

- 自动定位两市场分日 snapshot、证券映射和已有实验。记录真实字段、日期范围、采样间隔、时钟和既有 1min IC 定义。若有历史成绩，带上代码版本、日期和口径；此前讲义给出的是待检验假设。开跑前固定主 IC。若项目有明确的既有主 IC，沿用并同时报告下述可比较口径；否则下述 Pearson 截面 IC 为主。
- 决策点默认同一市场同步的 5 秒网格。每个时点只取当时已收到的最后有效报价；没有接收时钟时用数据源时间并写明。m=(bid1+ask1)/2，r_h=10,000×ln[m(t+h)/m(t)]，单位 bp。两端用向后 as-of，处于同一连续交易段；陈旧上限按市场预先固定（默认 max(5s, 3×训练期典型推送间隔)）。停牌、交叉盘、越午休/收盘或缺端点屏蔽。保留有效的零收益。
- 各市场同一时刻对可用股票计算 Pearson(pred, r60)，至少 20 只且两边方差非零。先按时点平均为日 IC，再等权平均交易日；同步报有效日、时点、股票数及覆盖率。辅报截面 RankIC 与按股日计算的时序 Pearson IC。评估始终比较同一组有效锚点，不用全市场所有样本混成一个相关系数。
- 在共同覆盖期按两个市场共同交易日期确定边界：最后约 15 个共同交易日留作 test，紧前约 15 个留作 validation。按两个边界日期给各市场所有交易日分 train/val/test，并以共同覆盖期末为本轮评估截止；台湾更早历史全部纳入 train。覆盖不足则在开跑前按共同日期 70/15/15 切。将实际边界写入配置。切分处删除最远监督端点跨界的训练锚点，所有预训练头也服从切分。测试标签只在各市场方案锁定后统一评一次。
- 一次冒烟即可：抽台港各一日查字段与收益单位、确认截断 t 后输入不会改变 t 的预测、跑通一次前反向和 IC。CPU 并行训练一个便宜基线：当前 snapshot 的相同归一化字段 → Ridge → r60。

## 2 · 输入与主干

- 输入只用 snapshot 本身约 20–30 个可见数值字段（以真实 schema 为准）、字段存在性、推送时间差和市场标记。价格保留两组坐标：各档相对当前中价的 bp 距离，以及相邻可见帧中价的对数变化（调用 mid_move_bp 并输入有效位）。这是原有价格的重新编码；整本盘口平移一档时仍能识别跳价。跨证券、停牌、断流和交易段边界复位前值。数量用 log1p；已有累计字段按其语义处理。禁止额外构造 OFI、技术因子或加入逐笔数据。每次推送产生一个 token，按连续交易段打包；同一时点有多个 5 秒锚点复用最近隐状态及其年龄，避免为每个锚点重复读取整窗。无历史或过旧则跳过。按交易时段重置状态。
- PLE 对每个数值字段按训练折分位数取 16 段，去重重合结点；每段编码该区间已填比例，端外截断并保留越界位，常数字段单独处理。两市同语义字段共享投影，量纲差异用各市场训练统计校准。PLE、缺失位、时间编码拼接后投影到 d=128。主干用因果 Mamba，4 层，d_state=16，expand=2。训练片段 256 个 snapshot，前 32 个作 warm-up，其余有效位置可共享前向；验证与测试按时间顺序回放并一致处理状态。
- 用 PyTorch、已兼容的 mamba-ssm、BF16（不支持时用带 scaler 的 FP16）、AdamW、梯度裁剪 1.0。预训练 lr=3e-4、wd=0.01、5% warm-up 后余弦衰减。每卡批量沿用第 0 节的实测值，以梯度累积保持同一候选有效批量。两卡共享相同字段表。若 fused kernel 在 30 分钟内仍无法打通，使用环境已有的可用 Mamba 实现；若只能以 GRU 保底，明确标注主干替代。

## 3 · 双市场多头预训练（3–22h）

| 头 | 标签与损失 | 权重 |
|---|---|---:|
| 60s 收益（主头） | r60 / s60，Huber(δ=1)；s60 为对应市场训练折收益的稳健尺度，尺度退化用训练标准差并设正下限 | 1.00 |
| 多周期收益 | r10、r120、r300，各用本市场、本周期训练尺度，三个 Huber 取均值 | 0.25 |
| 下一帧盘口 | 预测下一条真实推送的中价变化(bp)、价差变化(bp)、可用前 3 档双侧 log 深度变化；按字段训练尺度标准化，Huber 均值 | 0.25 |
| 未来波动 | 在有效 5 秒中价网格算未来 60s 和 300s 的 RV=Σr5²（bp²），回归标准化 log(1+RV)，Huber | 0.15 |
| 市场方向 | 从当期可见且两端有效的股票构造同市场 60s 等权平均收益，按训练期固定阈值分上/平/下，交叉熵；同一市场时点等权 | 0.10 |
| 掩码重建 | 约 1/4 训练片段只做重建：随机遮约 15% 有效字段，交替用同侧同档价量组或连续 4 帧的字段块；掩码在 PLE 前施加，同步屏蔽能还原目标的中价变化及下一帧差分旁路；从可见字段构造价格参考，遮掉参考时用上一有效帧中价，去除同义字段旁路。因果状态恢复原始归一化目标，只在被遮处算 Huber | 0.15 |

干净片段训练前五头，出分始终用干净输入。每头先对有效标签取平均，再加权；无有效目标则跳过。下一帧须在同一时段且间隔≤300s，长时间无快照不硬填。市场方向仅作未来标签；其训练阈值按唯一市场时点拟合，缺少有效横截面时跳过。训练尺度取训练折 MAD×1.4826，若为零用训练标准差，下限 1e-3 bp；评估用原始 bp 标签，主收益头输出换回 bp 评 IC。把这组实验标作含收益监督的联合预训练。

启动一个双卡 DDP 作业。每个全局优化步包含 TW 和 HK 的训练片段，共享一套 PLE 投影、Mamba 主干及预测头；两个 rank 同步梯度并更新同一组权重。每个片段只含一个市场、一只证券的连续交易时段。按日期、证券分片连续读取，DDP 各 rank 读取互斥分片；每个 epoch 轮过全部可用训练分片，每个市场每个任务按跨 rank 的有效数归一，然后按两市场等权。DDP 默认平均各 rank 梯度时，本地可微分 loss sum 乘 world_size / 全局有效数，只 all-reduce 分母；全局无标签时该头图连通、梯度为零。首 200 个稳定 step 测端到端吞吐，估算含验证的 epoch 时长。目标 3–5 个 epoch，第 22 小时留出微调。若预计不足 3 轮，先改成每 10s/20s 一个训练监督锚点；若主耗时在扫描 token，再降到 d=96、3 层，并对每个证券日按固定步长轮换抽连续片段，保留全市场、全训练日期覆盖。记录每轮实际读取的原始帧数、覆盖率与抽样步长；抽样轮和全量遍历分别注明。评估网格固定 5s。每轮保存可恢复 checkpoint（权重、优化器、scheduler、随机状态、步数、字段/PLE 配置），输出 TW/HK val IC 与各头有效数和 loss。取两市 val 主 IC 等权均值最高的一轮为共享起点；同分选更早轮。将该轮登记为 joint/best 并记录文件哈希。

## 4 · 单市场微调与对照（22–33h）

退出 DDP，启动两个独立的单卡作业：GPU 0 只读 TW 训练集，GPU 1 只读 HK 训练集。两者各自加载 joint/best 的副本、重置优化器，分别写入 finetune/TW 和 finetune/HK；每种微调方案都从该市场的同一初始副本重新开始。每市场从同一个最佳联合 checkpoint 出发，保留 60s 头，只按该市场 60s Huber 训练。每轮按本市场 val 主 IC 选优，最多 3 轮，连续两轮不改善即停。每个市场只在本市场 validation 上选方案：

1. 先评联合头和冻结主干的线性探针（lr=1e-3），并留出时间跑同主干单市场从零训练 r60 对照（lr=3e-4、相同下游更新步数）。它们分别衡量直接迁移、状态可读性和完整预训练流程增益。
2. 全量微调的头 lr=3e-4。主干 lr 候选为 1e-5、3e-5。若主指标是截面 Pearson，同时试 `target_loss` 的 IC 权重 0、0.15：Huber 保留 bp 标尺，相关性项对齐同一市场、同一 5s 时点的股票排序方向。输入形状为 [时点组, 股票]，每个有效组至少 20 只；相同股票只出现一次。随机选时点，再在组内均匀选最多 32 只同期股票。显存紧时按单个时点顺序处理、跨时点梯度累积，必要时采用 activation checkpointing；仍无法容纳 20 只时仅用 Huber，并记录原因。禁止跨市场、跨时间或在互不关联的 microbatch 上凑相关系数。若项目主 IC 是时序口径，保留 Huber 并按既有口径选 lr。若主干批量试验最多容纳 16 个片段，先验证冻结状态的线性头上完整截面相关损失，再决定是否给全量微调启用该项。
3. 两卡各自对本市场执行等预算筛选。每个合法组合从同一 joint/best 和随机种子开始，用相同顺序的训练锚点、固定验证面板，试跑最多 0.25 个训练 epoch。先实测单步耗时；所有短跑合计不超过该市场微调预算的 25%。若超时，先固定 lr=3e-5 只试损失开关，再退为单一 Huber 基线。按该市场 val 主 IC 排序，平分选 Huber；保留前两名，余时从各自 checkpoint 续跑至相同总预算（最多 3 轮），在完整验证集择优。未跑候选明确列为未测。
4. 预算仍有余量再试 LoRA（r=4、α=8、adapter lr=3e-4）并确认 adapter 有非零梯度。若希望单独归因辅助任务，再做同两市、同预算的 r60-only 联合预训练。小样本验证无法识别唯一最优值，交付时报告实测候选及相对简单基线的按日配对差异。

## 5 · 锁定结果与交付（33–36h）

先写出每市场实际 lr、IC 权重、批量、截断长度、选中轮次、验证 IC 与候选试验步数（包括资源触发的降级）。两市分别按 validation 主 IC 选好微调方案、轮次与权重，写入 selection.json，然后一次性对锁定模型和预先指定的 Ridge、直接监督基线做 test。输出一张表：市场、模型、val/test 1min Pearson IC、RankIC、时序 IC、有效日及相对基线增量。对同一批预测再计算与 10–60 秒收益的 IC，判断信号是否集中于前十秒。用按日期配对的块 bootstrap 给主 IC 与增量估计区间，注明测试天数少时的不确定性。

交付可复跑命令、冻结配置/数据清单、每轮 metrics.csv 与 checkpoint、最优路径、四格结果和一段中文结论；列出实际 GPU 小时与未完成对照。0.30 未达到就写真实差距，不根据 test 改模型、改 IC 定义或筛股票。计时从检查数据开始；按吞吐及时缩减可选实验，优先交付两个市场完整的预训→微调→独立测试闭环。现在直接执行。
