

### 对前版说明的更正

- `Sr7ResidMR` 的指数分段输出被末尾赋值覆盖，**最终实际输出负残差**。
- `Sr7Reverse` 的节流与价格出窗条件会使正常路径只保留一个价格，**在正常递增时间戳、i>0时实际输出零**。
- `Sr7TRIX` 既不是三重EMA，也不是标准三重p点SMA：首层实际保留3p−1点却除p，末层输出相邻两点比值。本手册按实际过程展开。

## 统一符号与共用公式

| 记号 | 含义 |
|---|---|
| b₁、a₁；b_k、a_k | 买一/卖一及第k档报价；源码索引0对应第一档 |
| qᵇ_k、qᵃ_k | 第k档买/卖可见数量；具体单位由合约定义 |
| m、spread | 中间价 `(b₁+a₁)/2`、最优买卖价差 `a₁−b₁` |
| p_last | 最新正常成交价，可能早于采样时间 |
| B(x)、A(x) | 从各侧最优报价向外x bp范围内买/卖量和 |
| BUY / SELL | 源码成交side标签；是否指主动方向须核对上游适配 |
| Q、T、VWAP | 成交数量和、成交额和、`T/Q`，部分实现另除合约乘数 |

| WMA_N(x) | 最近N点以最早1、最新N的权重加权，除`N(N+1)/2` |

### 1bp分桶不是交易所一档

多数分桶算法从本侧最优价出发，以 `最优价/10000` 为一个桶的价格宽度，把多个交易所价位合并。首桶是最近1bp区域，不一定只有一档。部分实现用截断取整，部分用round四舍五入，不能把同名桶量视为完全相同输入。

```text
买侧桶索引：floor[(买一价−当前买价)/(买一价/10000)]
卖侧桶索引：floor[(当前卖价−卖一价)/(卖一价/10000)]
```

### EMA与EW统计

标准秒半衰期EMA（Δt与h同单位）：

```text
ρ = exp(−ln2×Δt/h)
E_new = ρE_old+(1−ρ)x
```

事件半衰期N：`ρ=exp(−ln2/N)`，每次有效更新递推一次。直接权重EMA则明确写 `E_new=(1−α)E_old+αx`，参数α不自动表示半衰期。

常见EW方差/协方差使用旧均值的偏差δ，先计算：

```text
δx=x−μx_old，δy=y−μy_old
μx_new=μx_old+(1−ρ)δx，μy同理
vx_new=ρ[vx_old+(1−ρ)δx²]，vy同理
cov_new=ρ[cov_old+(1−ρ)δxδy]
EW_corr=cov/sqrt(vx×vy)
```

本手册中的通用EW记号表示这类递推口径，具体初始化、极小分母与更新先后按各卡片注明。**若源码把ρ赋给当前样本而非旧状态，或把方差当标准差使用，均在该因子单独说明，不能自动改成标准形式。**

### 事件、可用时间与零值

- **成交触发**可以积累数量，不一定立刻发布因子；**深度触发**可能更新盘口计算；**Bar触发**可能结算、采样或只刷新时间戳。
- 默认很多模块订阅1秒Bar，但参数n/p/a可能仍按事件、笔数、档位或bp计。
- 公式描述正常有效路径。预热未满、空盘口、无成交、零分母和提前return时，各实现可能置零或保留旧值；**零不一定代表市场中性**。
- 数据订阅、订单簿更新顺序及依赖模块在同Bar中的调度由外部框架决定；当前目录不能独立证明这些事件已严格同步。
- 几乎所有标的相关模块都需`ukey`。加载名通常与类名相同；例外是`demo`、`lgbm`、`ult_lgbm`，`GetData`未在Factory注册。

**参数与窗口**：a默认5秒、b默认30秒；p默认20事件极值窗；bound=1.0固定。

**数值怎么读**：正值表示轨道状态信号下降，最终差分方向与g本身相反。

**如何使用**：作为突破/反转状态变化特征，不是可直接运行的完整R-Breaker交易规则。

**有效性判断**：存在明确实现或口径疑点，不能按通常指标含义直接使用；尚无数据证明预测有效。

**限制与失效来源**：多轨定义与常见日频版本不同，基于滚动mid；卖一量EMA比可有零分母，需保留最终差分方向。

**轨道状态g的完整分段**（H≠L，bound=1，Z为上述数量EMA比）：

```text
旧g<−1：先令g=0.8旧g；若L<OB且m>RB，改为g=(m−RB)/(RA−RB)×Z+1。
旧g>+1：先令g=0.8旧g；若H>OA且m<RA，改为g=(m−RA)/(RA−RB)×Z−1。
其他：m>BB时g=(m−BB)/(BB−BA)×Z+1；
      m<BA时g=(m−BA)/(BB−BA)×Z−1；
      轨道内g=2(m−BA)/(BB−BA)×Z−1。
H=L时g=0。最终f=旧g−新g。
```

当C位于构造的[L,H]内时，P也位于其中，`L<OB=P−H+L`与`H>OA=P+H−L`分别要求P>H、P<L，均不成立。因此正常情况下，两条“旧g越界后的反转子分支”不可触发，只保留0.8衰减。这是对源码条件的静态推导。

## 如何理解整库的有效性

### 可以从源码直接回答的部分

| 情况 | 代表实现 | 可以得出的结论 |
|---|---|---|
| 当前正常路径为常数零 | Sr7Event、Sr7Reverse、DemoAlpha | 当前没有时序变化信息，不能视为独立方向预测因子 |
| 主要公式同构或翻号 | Sr9EmaDiff / Sr10EmaDiff；SizeCorr / Correct | 不同名字不一定代表独立信息，反号本身不增加信息 |
| 同参数特例 | VOI6(b=50) / VOI6Fast；Sr8 / Sr12 mid EMA | 默认值/边界不同不能当实证收益差；数学同源需识别 |
| 名称不能代表通用公式 | Atr、Cmo、FillRate、Hurst、SizeEntroy、TRIX等 | 应按本手册实际公式解释，不能套同名指标的现成阈值 |
| 有明确实现/路径疑点 | MT、Sr5Macd、Sr7HMA、Sr8MACD等 | 不能直接按设计名称使用；疑点也不能凭空证明收益为负 |
| 仅衡量状态/风险 | BookVariance、Volatility、Slope、ShadowVolDiff等 | 没有天然做多/做空方向，仍可能作为交互或过滤有用 |
| 数据/工具/模型容器 | PriceBase、AlphaDumper、lgbm等 | 需要派生特征或外部训练定义，不能按独立因子判断收益 |

### 机制成立也会失效的典型场景

- **盘口量压力**：挂量可以快速撤销；大量挂单也可能只是被动承接，而非即将推动价格。
- **动态盘口变化**：深度减少同时包含成交、撤单和价位移出；没有逐订单证据不能精确分辨。
- **成交方向压力**：同向成交既可能推动价格，也可能被对侧完全吸收；side定义或事件对齐错误会改变结论。
- **趋势/反转**：二者需要不同市场条件；某时距有效不代表其他时距有效。
- **相关和残差**：样本非平稳、重叠、事件频率变化和当前样本入统计，都可能让数值看起来有意义而没有未来预测力。
- **标准化和非线性**：小方差/小分母会制造尖峰，阈值及常数可能仅适合某个标的尺度。
